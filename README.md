# Torn City Calendar Alerter
Shows the player the Torn event calendar so you don't need to miss those events ever again!

Install into TamperMonkey https://www.tampermonkey.net/

# Overview
On most pages of Torn City, you will be able to see up and coming or currently running events live from the Torn City event calendar.
